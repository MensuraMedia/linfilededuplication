Multi-source scanning, per-source progress & History

A preview for review — not the live app. Shows the proposed Scan-page changes for scanning several drives at once, and the History page.

① Scan several sources (folders & drives) as one pool to find duplicates across them · ② a percentage ring per source while scanning · ③ a History page that shows the last dedup operation with before/after bars and the space saved.

Options & file types

Find image near-duplicates · Include hidden · Minimum size · File-type filter (All Files / Enter Extension) — unchanged, applied to every source.

Keeper tiebreak adds a preferred source: when two copies are otherwise equal, the one on the first-listed source (your primary drive) is kept, so the copy on the backup/removable drive is the one removed.

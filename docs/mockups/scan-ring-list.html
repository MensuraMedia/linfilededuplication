LinFileDedup · Mockup

Scan progress as a per-source list

A preview for review — not the live app. Replaces the grid of rings so full paths fit, with a per-file activity bar so large files never look hung.

Each source is a row: the ring (overall % for that source) on the left; on the right the full path being scanned, the file name, a small activity bar (fast for small files, a slow crawl on a big file — never frozen), and a reassurance note.
